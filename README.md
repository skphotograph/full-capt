# Full Capt

Chromeで開いているWebページを自動で縦横にスクロールし、画面外の内容も含めて1枚のPNGにする拡張機能です。撮影後にプレビューが開きます。

## インストール

1. Chromeのアドレスバーで `chrome://extensions` を開く。
2. 右上の「デベロッパー モード」をオンにする。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、`manifest.json` があるこのフォルダーを選ぶ。
4. ツールバーの拡張機能メニューから、Full Captを固定する。

ビルドやライブラリのインストールは不要です。Chrome 121以降が必要です。コードを更新したら、拡張機能の管理画面でFull Captを再読み込みしてください。

## 使い方

撮りたいページでFull Captのアイコンを押します。撮影中はそのタブを開いたままにしてください。完了すると元のページのスクロール位置が戻り、プレビュータブが開きます。「画像をコピー」でクリップボードにコピーできます。画像を受け付けるアプリで `Ctrl+V` を押して貼り付けてください。「PNGを保存」では画像をファイルに保存できます。

## 通信と権限

拡張機能はスクリーンショットの撮影、結合、PNGの生成をすべてChrome内で行います。通信処理、解析サービス、外部ライブラリは使わず、拡張機能ページのCSPで `connect-src 'none'` を指定しています。生成した画像はプレビュータブのメモリ上にあり、「PNGを保存」を押すとファイルになります。権限は `activeTab` と `scripting` です。

読み込み済みのページならオフラインで撮影できます。撮影先のWebページ自身は、自動スクロールに応じて画像や追加コンテンツを取得することがあります。

## 撮影できる範囲

- Webページ本体のスクロール範囲が対象です。独立した内部スクロール領域や埋め込みフレームは、画面に描画されている部分を撮影します。
- 固定表示の要素は原則として最初に撮影する画面に入り、追従する要素はページ内の元の位置で撮影されます。
- `chrome://` のページやChrome内蔵PDFビューアなど、Chromeがスクリプトの実行を制限するページは対象外です。
- 撮影中にページの寸法が変わると、最新の寸法で先頭から最大2回まで自動で撮り直します。無限スクロールなどで寸法の変化が続く場合は中断します。PNGの上限は各辺32,767ピクセル、総面積8,000万ピクセル、撮影120枚です。
